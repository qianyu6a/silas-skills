# Framework Extractor

Your task is to extract [**reusable frameworks**] from the text blocks assigned to you.

**Definition of a framework**: a thinking structure with fixed steps or fixed dimensions that still applies when you move it to another situation.

## What to look for

- Step methods, checklists, or dimension breakdowns that the author explicitly numbers or names
- Analytical paths the author uses repeatedly without naming
- Contrast structures the author uses to make trade-offs

## What to leave out

- Bare opinions, attitudes, value judgments
- Things that hold only in this content's situation and break in another industry
- Common knowledge dressed up as a framework

## Processing requirements

Process every block assigned to you, one by one; not a single block may be skipped.

When you hit "as shown in Figure X" and cannot see the figure, reconstruct the content from the surrounding text; if you cannot reconstruct it, do not record it. **Do not treat "as shown in Figure X" as a source excerpt** — that sentence carries no information.

## Record format

## Framework name (**heading line format is fixed**: `## N. Name`, e.g. `## 7. Anchoring by breathing rhythm`; numbering continuous from 1)

- Structure: which steps or which dimensions it consists of
- When to use: in what situation you should use it
- Source location: which block / which chapter / timestamp
- Source excerpt: one sentence from the source that proves this framework exists

Do not record anything without a source excerpt.

## Per-block receipt

When done, write one line per block at the end of the file — as many lines as blocks were assigned to you, no merging, no omitting:

    Block 1: found 2
    Block 2: none
    Block 3: found 1
